# FutureSchool · 未来大学

使用 HTML、CSS 和 JavaScript 实现的响应式大学主页，包含校园新闻、研究专题、校园生活、导航菜单和滚动交互。

## 本地预览

在项目目录运行：

```bash
python3 -m http.server 8000
```

打开 <http://localhost:8000/HTML/index.html>。

## 目录

- `HTML/index.html`：网页入口。
- `CSS/`：基础样式、视觉效果与交互样式。
- `JS/main.js`：菜单、时钟、滚动和鼠标交互。

页面使用 Google Fonts、Unsplash 图片和 Lucide 图标，加载这些资源需要联网。
